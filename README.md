## 🖨️ HOW TO PRINT:

### Step 1: Get OpenSCAD
Download free: **openscad.org**

### Step 2: Open & Export Each Part
1. Open `chest-plate.scad`
2. Press **F5** to preview
3. Press **F6** to render
4. **Design → Export → Export as STL**
5. Repeat for each part

### Step 3: Slice in Bambu Studio
1. Open Bambu Studio
2. Import all `.stl` files
3. Arrange on build plate
4. Set **Layer Height**: 0.16mm
5. Set **Infill**: 20%
6. Enable **Supports**: YES
7. **Slice → Print!**

---

| Head + Neck | 0.12mm | 15% | YES | Ears need support |
| Arms | 0.16mm | 20% | YES | Hands need support |
| Legs | 0.16mm | 20% | YES | Foot arch needs support |
| Cat Ears | 0.12mm | 15% | YES | Pointy tips need support |

## ✏️ POST-PROCESSING:

1. **Remove supports** carefully
2. **Sand** any rough edges (start 400 grit, then 800)
3. **Drill** LED holes if needed
4. **Paint** with blue + gold acrylic!
5. **Glue** LEDs in place
6. **Assemble** with snap-fits!

3. **Install LEDs**
4. **Connect electronics**
5. **Snap together:**
   - Legs → Chest plate
   - Arms → Chest plate sides
   - Neck → Chest plate top
   - Head → Neck
6. **Mount electronics**
