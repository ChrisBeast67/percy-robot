## 🖨️ HOW TO PRINT:

### Step 1: Get OpenSCAD
Download free from: **openscad.org**

### Step 2: Open the files
- Open OpenSCAD
- File → Open → select `.scad` file

### Step 3: Preview
- Press **F5** to preview the3D model

### Step 4: Export STL
- Design → Export → Export as STL
- Save with the same name (e.g., `chest-plate.stl`)

### Step 5: Slice and Print
- Use **Cura** or **PrusaSlicer** (free)
- Import your `.stl` file
- Recommended settings:
  - Layer height: 0.2mm
  - Infill: 20%
  - Supports: YES for overhangs
  - Material: PLA (blue or white)

## 🔧 AFTER PRINTING:

1. **Sand** any rough edges
2. **Paint** with blue + gold acrylic paint!
3. **Drill** holes for LEDs
4. **Glue** LEDs in place
5. **Assemble** with screws + glue
